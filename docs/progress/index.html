Milestone 2: Real captures into the viewer

2/8 done · 6 open

  • Done

    Capture bundle import

    Drop *.bikecapture.zip on the viewer, unzip in the browser (fflate), load model.usdz, read manifest.json and poses.json, name the scene from the manifest. Unit-test the bundle parser with a synthetic zip.

  • Open

    Keep captures across reloads

    Cache the unzipped model of the last opened bundles in IndexedDB/OPFS (best effort, quota-aware) so a reload reopens a capture scene without re-dropping the .bikecapture.zip.

  • Done

    USDZ robustness

    Three r186 reads binary USDC; apps/web/src/viewer/usd/ fixes its inline-value decoding, speeds up large meshes ~10×, waits for packed textures and falls back to a tools/usdz-to-glb.py hint. Synthetic Object-Capture-like fixtures from tools/fixtures/make-usdc.py.

  • Open

    Verify a real Object Capture USDZ

    Load a real model.usdz (owner's iPhone, see docs/MANUAL-STEPS.md), compare against Quick Look; turn anything off into a fixture-based test (synthetic re-creation, never the capture itself).

  • Open

    Weld USDZ meshes

    Three expands face-varying meshes to 3 vertices per triangle (~3M vertices for a 1M-triangle capture); merge identical corners into an indexed geometry to cut GPU memory, and consider decimating for phones.

  • Open

    Auto-orient captures

    Detect the ground plane / longest horizontal axis so a scanned bike stands upright facing +X; expose rotate/scale/offset controls in Edit mode (writes model.rotation/scale/offset).

  • Open

    Crop box for area-mode / splat captures

    Draggable box in Edit mode that clips everything outside (clipping planes), saved in the scene, so area-mode scans get a clean background.

  • Open

    Photo close-ups per area

    Use poses.json to find the capture photos that look most directly at each area target (angle + distance score) and show them as a filmstrip under the area; tap to open full screen. HEIC → JPEG conversion at export time on iOS if browsers can't decode HEIC.

Milestone 4: iOS app depth

0/5 done · 5 open

  • Open

    In-app viewer

    RealityKit/SceneKit view of model.usdz with the same areas and comments (read bike-scene/1 JSON), so sales staff can present from the phone offline.

  • Open

    Capture guidance for bikes

    Checklist overlay (3 orbits: hub height, saddle height, top-down; close-ups of fork crown, dropouts, rear derailleur, cockpit), shot counter per pass, tips for reflective paint (dulling spray / polarizer), turntable support.

  • Open

    Mac high-detail reconstruction

    tools/mac-reconstruct Swift CLI running PhotogrammetrySession at .full / .raw detail from an exported bundle, writing model.usdz + poses.json back.

  • Open

    On-device GLB export

    Convert the USDZ to GLB (ModelIO → glTF writer) so the web viewer never needs conversion.

  • Open

    Upload to viewer

    Share sheet target / direct upload of bundles to the web app storage (see Milestone 5).
